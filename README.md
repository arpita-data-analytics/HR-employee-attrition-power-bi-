# 📊 HR Analytics — Employee Attrition & Performance Dashboard

## 🚀 Project Overview
This project features an interactive Power BI executive dashboard built to analyze workforce attrition patterns within an enterprise organization. By evaluating turnover across departments, job roles, overtime status, job levels, and age demographics, the dashboard enables HR leadership to identify retention risks and make data-driven workforce management decisions.

## 📈 Executive Dashboard Preview
![HR Analytics Dashboard Preview](dashboard_preview.png)

## 🔑 Key Performance Indicators (KPIs)
- **Total Employees:** 1,470
- **Total Attrition:** 237 employees
- **Attrition Rate:** 16.1%
- **Average Monthly Income:** $6,503
- **Average Age:** 36.9 years
- **Average Job Satisfaction:** 2.7 / 4.0

## 🔍 Key Analytical Insights
1. **Overtime Impact:** Employees working overtime show significantly higher attrition compared to non-overtime staff.
2. **Job Role Trends:** Laboratory Technicians, Sales Executives, and Research Scientists experience the highest total attrition counts.
3. **Career Progression:** Attrition drops substantially at higher Job Levels (Levels 3–5), indicating turnover is concentrated among entry and mid-level employees.
4. **Demographic Concentration:** The 25–34 age group accounts for the largest proportion of employee turnover.

## 🛠️ Tools & Skills Demonstrated
- **Power BI Desktop:** Report design, grid layout structuring, interactive slicer integration, and visual formatting.
- **Data Modeling & DAX:** Creation of custom calculated measures for Attrition Rate (%), Average Income, and Average Satisfaction metrics.
- **Interactive Slicers:** Filtering by `OverTime`, `JobRole`, and `Department` for dynamic drill-down capabilities.
